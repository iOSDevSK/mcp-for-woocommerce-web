## Authentication Settings

### JWT Authentication Configuration

## Configuration Options
The Settings tab has two switches:

- **Enable MCP functionality** turns the MCP endpoints on or off
- **Require JWT Authentication** decides whether every request needs a token

## Security Considerations
With JWT authentication on, which is the default:
- Every MCP request needs a valid token
- The assistant can read what the token's user can read
- Use this on a live store

With JWT authentication off:
- Anyone who knows the endpoint can call the tools without a token
- The tools still only read, and they still skip customers and orders
- Fine for local development, or for a public assistant that only needs the catalogue
