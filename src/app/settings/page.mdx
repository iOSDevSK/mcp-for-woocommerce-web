## Configuration Options
The settings screen at **Settings > MCP for WooCommerce** has five tabs:

- **Settings**: the **Enable MCP functionality** switch, and the **Access** card with your MCP endpoint URL
- **Documentation**: how to connect a client
- **Tools**: a switch for each of the 31 tools
- **Resources**: the search guide resource
- **Prompts**: the prompt list, currently empty

The Tools, Resources and Prompts tabs open only while MCP is on.

## Access
While MCP is on, the endpoint is public, like the WooCommerce Store API:

- No token or login is needed, and the plugin never signs in as a WordPress user
- Every tool only reads; nothing can be created, changed or deleted
- It returns only storefront data: published products, variations, categories, tags, brands, attributes, approved reviews, shipping and tax rates, the payment methods offered at checkout, and published posts and pages
- It never returns orders, customers, users, e-mail addresses, store settings, or draft, private or password-protected content

## Stopping Access
- Switch **Enable MCP functionality** off to close the endpoints
- Switch individual tools off on the **Tools** tab to hide them from the assistant
