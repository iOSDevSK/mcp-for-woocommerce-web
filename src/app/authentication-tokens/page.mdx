# Authentication Tokens

## What are Authentication Tokens?

An authentication token lets an MCP client, such as Claude Desktop or Webtalkbot, connect to your site. Tokens are JWTs (JSON Web Tokens), so the site can check them without storing a session.

### How They Work

- A token carries the role and permissions of the user who created it
- It works only on the MCP endpoints
- It expires after the duration you picked, unless you chose no expiry
- You can revoke any single token without touching the others
