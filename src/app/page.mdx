# MCP for WooCommerce

**MCP for WooCommerce** is a specialized WordPress plugin that connects WooCommerce stores to AI assistants like Claude via the Model Context Protocol (MCP). This **read-only plugin** provides secure access to public store data while protecting customer privacy.

### What MCP for WooCommerce Does:
- **Connects WooCommerce to AI** assistants in 5 minutes
- **Read-only access** to product data, shipping info, and store details  
- **Zero customer data exposure** - only public information accessible
- **Free WordPress plugin** based on Automattic's wordpress-mcp
- **Compatible with Claude AI** and other MCP-supported systems

### Key Benefits:
- ✅ **Quick Setup**: Install and configure in under 5 minutes
- ✅ **Secure by Design**: Read-only access protects sensitive data
- ✅ **AI-Ready**: Works with Claude, GPT, and other AI assistants
- ✅ **WooCommerce Optimized**: Specialized for e-commerce needs
- ✅ **Free & Open Source**: No licensing costs or restrictions {{ className: 'lead' }}
