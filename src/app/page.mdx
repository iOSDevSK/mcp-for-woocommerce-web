# MCP for WooCommerce

**MCP for WooCommerce** is a free WordPress plugin that lets an AI assistant such as Claude read your WooCommerce store through the Model Context Protocol (MCP). The assistant can look up products, variations, categories, reviews, shipping, taxes and payment methods. It cannot change anything, and it only sees what a shop visitor can already see: no customers, orders or settings.

## What MCP for WooCommerce does {{ anchor: false }}

- Gives an assistant 31 tools, all of them read-only: 27 for WooCommerce data and 4 for WordPress posts and pages.
- Works with Claude Desktop, Claude Code, Cursor, VS Code and any other client that speaks MCP.
- Connects over Streamable HTTP to a public, read-only endpoint on your site, with no token or login.
- Takes about five minutes to install and connect.
- Is a fork of Automattic's wordpress-mcp, licensed GPL-2.0-or-later.

## Getting started {{ anchor: false }}

Install the plugin, switch MCP on in its settings and add your endpoint URL to the AI client you use. From then on the assistant can answer questions about your catalogue and your shipping, tax and payment options, and it reads them live, so the answers follow your prices and stock. {{ className: 'lead' }}
