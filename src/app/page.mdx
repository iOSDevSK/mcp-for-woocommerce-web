# MCP for WooCommerce

**MCP for WooCommerce** is a free WordPress plugin that lets an AI assistant such as Claude read your WooCommerce store through the Model Context Protocol (MCP). The assistant can look up products, variations, categories, reviews, shipping, taxes and payment methods. It cannot change anything, and the tools it gets do not reach customers or orders.

### What MCP for WooCommerce does

- Gives an assistant 33 tools, all of them read-only: 29 for WooCommerce data and 4 for WordPress posts and pages.
- Works with Claude Desktop, Claude Code, Cursor, VS Code and any other client that speaks MCP.
- Connects over HTTP with a JWT token, or through a small local proxy for clients that only run MCP servers as a process.
- Takes about five minutes to install and connect.
- Is a fork of Automattic's wordpress-mcp, licensed GPL-2.0-or-later.

## Getting started {{ anchor: false }}

Install the plugin, switch MCP on in its settings, create a token and add your site to the AI client you use. From then on the assistant can answer questions about your catalogue and your store settings, and it reads them live, so the answers follow your prices and stock. {{ className: 'lead' }}
