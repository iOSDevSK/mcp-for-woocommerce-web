The plugin gives an AI assistant 33 tools. All of them only read: 29 cover WooCommerce data and 4 cover WordPress posts and pages. The table lists every one of them.

<ToolsTable />

## Tool Configuration

Every tool has the functionality type **read**: it returns data and never changes anything.

## Toggle Controls

The **Tools** tab in the plugin settings has a switch next to each tool. A switched-off tool disappears from the list the assistant sees.

- **Blue, switch to the right**: the tool is on
- **Gray, switch to the left**: the tool is off

## What the Tools Can and Cannot Reach

- They read products, variations, categories, tags, attributes, reviews, shipping, taxes, payment gateways, system status, and WordPress posts and pages
- They cannot create, edit or delete anything
- None of them returns customers, orders or sales figures. The codebase has tools for those, but the plugin does not load them.

## Best Practices

### Product Search
1. Start with **wc_products_search**
2. Open a result with **wc_get_product** and the ID the search returned
3. Use **wc_intelligent_search** only when the first search comes back empty
4. Give the customer the product's permalink with every answer

### Performance
- Work with the IDs a search returns instead of hard-coded ones
- Ask for fewer results when you only need a few
- Page through large lists instead of loading them at once

### Asking the Assistant
- A specific question gets a better answer than a broad one
- Plain language is fine; the assistant picks the tools
- For a full answer it may combine several tools, for example a product and its variations

## Example Workflows

### Finding a Product
1. Search with **wc_products_search**
2. Get the details with **wc_get_product** and the returned ID
3. If it is a variable product, list the options with **wc_get_product_variations**
4. Answer with the product's permalink

### Reviewing WordPress Content
1. List content with **wordpress_posts_list** or **wordpress_pages_list**
2. Open an item with **wordpress_posts_get** or **wordpress_pages_get**
3. Ask for an SEO or content review of what came back

### Checking the Store Setup
1. Shipping: **wc_get_shipping_zones** and **wc_get_shipping_methods**
2. Payments: **wc_get_payment_gateways**
3. Taxes: **wc_get_tax_classes** and **wc_get_tax_rates**
4. System: **wc_get_system_status**
