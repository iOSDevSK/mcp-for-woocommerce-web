MCP for WooCommerce has no ready-made prompts yet. You ask the assistant in your own words and it picks the tools. {{ className: 'lead' }}

## Current Status {{ anchor: 'current-status' }}

The plugin ships tools and one resource, a search guide for the assistant, but no prompts. An MCP client that asks for the prompt list gets an empty one.

## Future Development {{ anchor: 'future-development' }}

Prompts may come in a later version, for example templates for common product questions or a store review. Until then the [33 tools](/tools) cover the same ground; the [setup guide](/setup#testing-the-setup) has questions to start with.
