## Current Status {{ anchor: 'current-status' }}

**Available Prompts**: No prompts are currently available.

The MCP for WooCommerce plugin focuses on providing read-only tools for accessing WooCommerce and WordPress data. No built-in prompts are currently available in the system.

## Future Development {{ anchor: 'future-development' }}

Pre-configured prompts may be added in future plugin versions to provide:

- Ready-to-use query templates
- Business intelligence prompts
- Store analysis templates
- Marketing insights prompts

For now, leverage the powerful set of 33 read-only tools to create custom queries that meet your specific business needs.
