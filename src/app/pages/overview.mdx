**MCP for WooCommerce** is an advanced AI integration plugin that connects WooCommerce & WordPress with the Model Context Protocol (MCP). It provides comprehensive AI-accessible interfaces to WooCommerce products, orders, categories, shipping, payments, and WordPress posts/pages through standardized tools, resources, and prompts.

## What is MCP?
[The Model Context Protocol (MCP)](https://modelcontextprotocol.io/) is an open standard for connecting AI assistants to external data sources and tools. It enables AI models to securely access and interact with your application data in real-time.

## Key Features

### Product Management (Read-Only)
- **Universal Product Search**: Primary product search tool for any store type
- **Product Details**: Get comprehensive product information with direct links
- **Product Variations**: Access colors, sizes, and other variation data
- **Product Categories & Tags**: Browse product taxonomies
- **Product Attributes**: Access global attributes and terms
- **Product Reviews**: Read customer feedback and ratings

### Store Information (Read-Only)
- **Shipping Zones & Methods**: Access shipping configuration
- **Tax Classes & Rates**: View tax settings by location
- **Payment Gateways**: Get available payment methods
- **System Status**: Monitor WooCommerce system health

### WordPress Content (Read-Only)
- **Posts & Pages**: Access WordPress content
- **Content Search**: Find specific posts and pages

### AI-Optimized Features
- **Intelligent Search**: Advanced search with automatic fallback strategies
- **Search Intent Analysis**: Analyze queries and suggest optimal parameters
- **Filtered Search**: Multi-criteria product filtering
- **Permalink Integration**: Direct links to all products and variations

## Architecture
The plugin implements a dual-transport architecture:
- **STDIO Transport**: Direct command-line integration
- **Streamable Transport**: HTTP-based streaming for web applications

## Security Features
- **JWT Authentication**: Secure token-based access
- **Tool States**: Enable/disable specific functionality
- **Audit Logging**: Track AI interactions

## Getting Started
1. Install the plugin in your WordPress/WooCommerce site
2. Configure authentication settings
3. Enable desired tools and features
4. Connect with Claude AI, [Webtalkbot](https://webtalkbot.com), or other MCP-compatible clients
