**MCP for WooCommerce** connects a WooCommerce store and its WordPress content to AI assistants through the Model Context Protocol (MCP). It gives an assistant read-only tools and resources for products, categories, reviews, shipping, taxes, payment methods, and WordPress posts and pages.

## What is MCP?
[The Model Context Protocol (MCP)](https://modelcontextprotocol.io/) is an open standard for connecting AI assistants to outside data and tools. This plugin turns your site into an MCP server: it tells the assistant which tools it offers, and the assistant calls them when a question needs your store's data.

## Key Features

### Products (read-only)
- Product search that works for any kind of catalogue
- Full product details, each with a link to the product page
- Variations such as colours and sizes
- Categories, tags, brands, attributes and attribute terms
- Approved customer reviews and ratings

### Shipping, taxes and payments (read-only)
- Shipping zones, enabled methods with their cost, and the locations they cover
- Tax classes and rates
- The payment methods offered at checkout

### WordPress content (read-only)
- Published posts and pages, listed with filters and search or opened by ID

### Search helpers
- An intelligent search that tries broader queries when the first one finds nothing
- Intent analysis that suggests search parameters for a question
- Filtering by category, brand, attributes or several criteria at once
- A permalink with every product and variation, so the assistant can link to it

## Architecture
The plugin is an MCP server inside WordPress. A client calls it directly over Streamable HTTP (JSON-RPC 2.0) at `/wp-json/wp/v2/wpmcp/streamable`; a WordPress REST-style endpoint at `/wp-json/wp/v2/wpmcp` is also available. Neither needs a token.

## Security Features
- The endpoint returns only what a shop visitor can already see; never orders, customers, users, e-mail addresses or settings
- No login: the plugin never signs in as a WordPress user
- No tool that creates, edits or deletes anything
- A switch for every tool, and a master switch that turns MCP off

## Getting Started
1. Install the plugin on your WordPress/WooCommerce site
2. Switch MCP on and copy the endpoint URL from the Access card
3. Leave on the tools you want the assistant to use
4. Connect Claude, [Webtalkbot](https://webtalkbot.com) or another MCP client

The [installation guide](/installation) walks through each step.
