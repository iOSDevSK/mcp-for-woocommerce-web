This page covers installing MCP for WooCommerce on a WordPress site with WooCommerce and checking that it works.

## Prerequisites
- WordPress 6.4 or later (tested up to 7.0)
- PHP 8.0 or later
- WooCommerce installed and active
- Composer and Node.js, only if you want to rebuild the plugin from source

## Installation Methods

### Method 1: WordPress Admin (Recommended)

1. Download the latest release from the <a href="https://github.com/iOSDevSK/mcp-for-woocommerce/releases" target="_blank">GitHub releases page</a>
2. Go to **Plugins > Add Plugin > Upload Plugin**
3. Upload the `.zip` file
4. Click **Install Now**
5. **Activate** the plugin

### Method 2: Manual Installation

1. Download the plugin ZIP from the GitHub releases page
2. Upload it to `/wp-content/plugins/`
3. Extract it there
4. Go to **Plugins** in your WordPress admin
5. **Activate** MCP for WooCommerce

### Method 3: From the Source Repository
If you want to change the plugin or contribute to it:

```bash
cd /wp-content/plugins/
git clone https://github.com/iOSDevSK/mcp-for-woocommerce.git
```

The repository includes the `vendor/` and `build/` folders, so the plugin runs as cloned. Rebuild only after you change PHP dependencies or the admin scripts:

```bash
cd mcp-for-woocommerce
composer install
npm install && npm run build
```

## Initial Configuration
Once the plugin is active:

1. Go to **Settings > MCP for WooCommerce** in your WordPress admin
2. On the **Settings** tab, switch on **Enable MCP functionality**
3. Decide whether to keep **Require JWT Authentication** on (it is on by default)
4. On the **Tools** tab, switch off any tool you do not want the assistant to use

## Verification
To check the installation:

1. The plugin shows as active in your **Plugins** list
2. **Settings > MCP for WooCommerce** opens
3. On the **Settings** tab, **Enable MCP functionality** is on
4. On the **Tools** tab, the tools you need are on

## Troubleshooting

### Common Issues

**The plugin won't activate:**
- Check that the server runs PHP 8.0 or later
- Check that WordPress is 6.4 or later

**Composer dependencies are missing:**
- Run `composer install` in the plugin directory

**Permission errors:**
- Check the file permissions of the plugin directory
- Make sure the web server can read the plugin files

**The settings screen is broken or incomplete:**
- Run `npm install && npm run build` in the plugin directory to rebuild the admin scripts
