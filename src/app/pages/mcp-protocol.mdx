MCP is an open protocol for how applications hand context to large language models (LLMs). Its own documentation compares it to a USB-C port for AI applications: one connector instead of a different cable for every device. {{ className: 'lead' }}

## What is MCP?

Before MCP, every AI application needed its own integration for every data source. With MCP, a data source such as your store runs one server, and any MCP client can use it.

## Key Benefits

- Many existing servers and clients you can combine
- One way to build your own integration instead of one per application
- An open specification anyone can implement
- You can switch AI clients and keep the same data sources

## How It Works

An MCP server describes what it offers in three kinds of items:

1. **Tools** the model can call, such as a product search
2. **Resources** it can read, such as a guide or a document
3. **Prompts**, ready-made instructions a user can pick

The client connects to the server, asks for the list, and the model calls what a question needs. MCP for WooCommerce is such a server for your store.

## Implementation Options

- Use existing MCP servers, like this plugin
- Build your own server to expose your data or tools
- Build a client, if you are writing an AI application

## For Developers

There are official SDKs for several languages. They handle the protocol itself, so your code only deals with your tools and data.
