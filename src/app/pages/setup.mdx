This page covers the plugin's settings and a ready configuration for each common MCP client.

## Plugin Settings
Access the plugin settings at **Settings > MCP for WooCommerce** in your WordPress admin.

### Basic Settings
**Enable MCP functionality**
- Turns the MCP endpoints on. Nothing else works until it is on.

**Require JWT Authentication**
- On by default. Every request then needs a valid token.
- Tokens are created on the **Authentication Tokens** tab, where you choose how long each one lasts: 1 hour, 24 hours, 7 days or no expiry.

### Tool Configuration
All 33 tools only read data. The **Tools** tab has a switch for each one; an assistant never sees a tool you have switched off. Leave on only what your use case needs.

## Client Configurations

### Claude Code
**Using HTTP Transport with JWT Token (Recommended)**

Add your MCP for WooCommerce server directly to Claude Code using the HTTP transport:

```bash
claude mcp add --transport http woo-mcp https://your-site.com/wp-json/wp/v2/wpmcp/streamable --header "Authorization: Bearer your-jwt-token-here"
```

Replace `your-site.com` and the token with your own values.

### Claude Desktop
**Using JWT Token with mcp-wordpress-remote (Recommended)**

Add to your Claude Desktop `claude_desktop_config.json`.

**This method uses the MCP WordPress remote proxy (requires Node.js to be installed):**

```json
{
    "mcpServers": {
        "woo-mcp": {
            "command": "npx",
            "args": [ "-y", "@automattic/mcp-wordpress-remote@latest" ],
            "env": {
                "WP_API_URL": "https://your-site.com",
                "JWT_TOKEN": "your-jwt-token-here"
            }
        }
    }
}
```

**PHP Version (requires PHP installed):**

```json
{
    "mcpServers": {
        "woocommerce": {
            "command": "php",
            "args": [ "/path/to/your/woo-mcp/mcp-proxy.php" ]
        }
    }
}
```

**Node.js Version (requires Node.js installed):**

```json
{
    "mcpServers": {
        "woocommerce": {
            "command": "/path/to/your/node",
            "args": ["/path/to/your/woo-mcp/mcp-proxy.js"],
            "cwd": "/path/to/your/woo-mcp"
        }
    }
}
```

### Local Development Configuration

To use with Claude Desktop for local development, add this configuration to your `claude_desktop_config.json`:

```json
{
    "mcpServers": {
        "woocommerce": {
            "command": "php",
            "args": [ "/path/to/your/woo-mcp/mcp-proxy.php" ]
        }
    }
}
```

### VS Code MCP Extension

**Direct Streamable Transport (JWT Only)**

Add to your VS Code MCP settings:

```json
{
    "servers": {
        "woo-mcp": {
            "type": "http",
            "url": "https://your-site.com/wp-json/wp/v2/wpmcp/streamable",
            "headers": {
                "Authorization": "Bearer your-jwt-token-here"
            }
        }
    }
}
```

### MCP Inspector (Development/Testing)

**Using JWT Token with proxy**

```bash
npx @modelcontextprotocol/inspector \
  -e WP_API_URL=https://your-site.com \
  -e JWT_TOKEN=your-jwt-token-here \
  npx @automattic/mcp-wordpress-remote@latest
```

## Transport Protocol Details

### STDIO Transport
- **Endpoint**: `/wp-json/wp/v2/wpmcp`
- **Format**: WordPress-style REST API
- **Authentication**: JWT tokens only
- **Use Case**: Legacy compatibility, works with most MCP clients
- **Proxy Required**: Yes (mcp-wordpress-remote)

**Why use it:**
- Works with clients that can only start an MCP server as a local process
- Uses the same JWT tokens as the HTTP transport

**Some of the tools:**
- `wc_products_search` - product search that works for any kind of catalogue
- `wc_get_product_variations` - all variations (colours, sizes and so on) of a variable product
- `wc_get_categories` - all product categories
- `wordpress_posts_get` - one WordPress post by ID
- `wordpress_pages_get` - one WordPress page by ID

The [tools reference](/tools) lists all 33.

### Streamable Transport
- **Endpoint**: `/wp-json/wp/v2/wpmcp/streamable`
- **Format**: JSON-RPC 2.0 compliant
- **Authentication**: JWT tokens only
- **Use Case**: Modern AI clients, direct integration
- **Proxy Required**: No

**Why use it:**
- The client talks to your site directly, with no proxy in between
- Standard JSON-RPC 2.0
- One hop less than the STDIO route

**Example Methods:**
- `tools/list` - List available tools
- `tools/call` - Execute a tool
- `resources/list` - List available resources
- `resources/read` - Read resource content
- `prompts/list` - List available prompts
- `prompts/get` - Get prompt template

## Testing the Setup

### Basic Connection Test

1. Open the AI client you connected
2. Ask: "What products do I have in my WooCommerce store?"
3. It should call the product search tool and list your products

### More Questions to Try

- "What sizes and colours does [product name] come in?"
- "Which shipping methods do you offer, and to which countries?"
- "Which payment methods can customers use?"
- "Show me the products in the [category name] category"

The plugin only reads, so a request to create or change something will fail. That is expected.

## Security Considerations

### Best Practices

- Serve the site over HTTPS; the token travels in every request
- Keep the plugin updated
- Switch off the tools you do not need

### Token Management

- Replace long-lived tokens from time to time
- Keep tokens out of shared documents and repositories
- A token acts with the permissions of the user who created it, so create tokens from an account with no more rights than the assistant needs

## Troubleshooting

### Common Issues

**JWT token expired**
- Create a new token on the Authentication Tokens tab
- Pick a longer duration if the old one ran out too soon
- Check that the server clock is correct

**Authentication failed**
- Check that the whole token was copied, with nothing missing at either end
- Check that the user who created it can read what you ask for
- Check that it has not expired

**Connection timeout**
- Check that the site loads in a browser
- Check whether a firewall or security plugin blocks `/wp-json/`
- Check that the SSL certificate is valid

**Proxy Issues**
- Update mcp-wordpress-remote to latest version:
```bash
npm install -g @automattic/mcp-wordpress-remote@latest
```
- Read the proxy's output for the actual error
- Check that `WP_API_URL` and `JWT_TOKEN` are set

### Token Durations

Pick the shortest duration that works: 1 hour or 24 hours for testing, 7 days for a trial run, and no expiry only for a server-to-server connection you control. Revoke a token as soon as you stop using it.
